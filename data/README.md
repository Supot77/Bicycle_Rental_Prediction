# ข้อมูลของกลุ่ม

อาจารย์จะจัดหา dataset ให้ ยังไม่มีข้อมูลจริงใน repository และไม่ดาวน์โหลดชุดอื่นมาแทน

- `raw/`: เก็บต้นฉบับที่ได้รับ ห้ามแก้ทับต้นฉบับ
- `processed/`: เก็บข้อมูลที่แปลงจากขั้นตอนที่ทำซ้ำได้
- ค่าเริ่มต้นของ Git จะไม่ติดตามไฟล์ภายในสองโฟลเดอร์นี้

เมื่อได้รับไฟล์ ให้ยืนยันหน่วยของหนึ่งแถว target ช่วงเวลา พื้นที่ แหล่งที่มา และสิทธิ์เผยแพร่ บันทึกใน `evidence/data_dictionary.csv` กับ `evidence/decisions.md` แล้วแก้ `config/project.json`

ตัวช่วยอ่านรองรับ CSV ก่อน หากได้ Excel/หลายไฟล์ ให้คุยวิธีอ่านและบันทึกการแปลง พร้อมเก็บต้นฉบับ หากจำเป็นต้องเปลี่ยน encoding หรือ delimiter ให้บันทึกเหตุผล

เมื่ออนุญาตให้เผยแพร่แล้ว กลุ่มค่อยตกลงวิธีส่งข้อมูล การใช้ `git add -f` ต้องเป็นการตัดสินใจโดยรู้สิทธิ์แล้ว ไม่ใช้เพื่อแก้ปัญหาไฟล์ไม่ขึ้น Git โดยไม่ตรวจ

ถ้าห้ามเผยแพร่ ให้ README ฉบับส่งจริงอธิบายวิธีที่อาจารย์เข้าถึงหรือดาวน์โหลดไฟล์อย่างถูกสิทธิ์
