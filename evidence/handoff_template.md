# แบบฟอร์มส่งต่องานระหว่างสมาชิก

เป็นแม่แบบ ยังไม่มีการส่งมอบหรือผลตรวจจริง คัดลอกเป็นไฟล์แยกเมื่อมีงานพร้อมส่ง

## ข้อมูลการส่ง

- Handoff ID / วันที่:
- ผู้ส่ง / ผู้รับ / ผู้ช่วยตรวจ:
- Task ID และจุดตรวจ G0–G6 ที่เกี่ยวข้อง:
- สถานะเสนอส่ง / รับแล้ว / ต้องแก้:
- สิ่งที่ต้องการให้ผู้รับทำต่อ:

## รุ่นและสิ่งที่ส่ง

- Notebook/code reference และลิงก์สำเนาที่แก้จริง:
- Dataset version / แหล่งไฟล์ตามสิทธิ์:
- Split manifest/version:
- Feature/schema version:
- Preprocessing recipe/version:
- Experiment/run ID และ settings:
- Artifact filename/version/checksum ถ้ามี:
- Python / รุ่นไลบรารีที่ใช้จริง:

## ข้อตกลง input/output

- Input ที่ต้องมี ชื่อคอลัมน์ ชนิด หน่วย และเวลาที่ทราบค่า:
- Output ที่ได้ หน่วย และข้อจำกัด:
- Learned preprocessing fit กับชุดใด:
- ผลคะแนนเป็น train / validation / test ชุดใด:
- Missing/unknown category/ผลติดลบหรือการปัดค่า จัดการอย่างไร:

## วิธีเปิดใน Colab ใหม่

- ลำดับ cell/ไฟล์ที่ต้องใช้:
- วิธีนำไฟล์เข้า runtime โดยไม่ต้องพึ่งตัวแปรค้าง:
- ตัวอย่างอ้างอิงที่เผยแพร่ได้และผลที่คาดหวัง:
- Tolerance หรือเงื่อนไขยืนยัน:
- ปัญหาค้างและงานที่ต้องรันใหม่หากแก้:

## ผลตรวจรับโดยผู้รับ

- วันที่และวิธีที่ลองจริง:
- ผลจริงและลิงก์หลักฐาน:
- รับงาน / ส่งกลับแก้ พร้อมเหตุผล:
- Task board และเอกสารที่อัปเดตแล้ว:

ห้ามใส่ข้อมูลจำกัดสิทธิ์หรือ secrets ลงแม่แบบสาธารณะ หากยังไม่มีผลจริงให้เว้นไว้ ไม่เติมผลสมมติแทนการตรวจรับ
